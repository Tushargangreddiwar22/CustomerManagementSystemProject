\# Customer Management System



\## Project Overview



Customer Management System is a web-based application developed using ASP.NET Core MVC, Entity Framework Core, and SQL Server. The system helps organizations manage customer records efficiently through a secure and user-friendly interface.



\## Features



\* User Registration and Login

\* ASP.NET Core Identity Authentication

\* Google Authentication

\* Facebook Authentication

\* Add New Customers

\* Edit Customer Details

\* Delete Customers

\* View Customer Information

\* Search Customers by Name and City

\* Entity Framework Core Integration

\* SQL Server Database Support

\* Responsive User Interface using Bootstrap

\* Error Handling and Validation



\## Technologies Used



\* ASP.NET Core MVC

\* C#

\* Entity Framework Core

\* SQL Server

\* ASP.NET Core Identity

\* Bootstrap

\* HTML

\* CSS

\* JavaScript

\* LINQ



\## Project Structure



\* Controllers – Handles requests and application logic

\* Models – Contains entity classes

\* Views – User Interface pages

\* Data – Database Context and Configuration

\* Services – Business Logic

\* Migrations – Database Migrations



\## Database



The application uses SQL Server as the backend database. Entity Framework Core is used for data access and database migrations.



\## Authentication



The system supports:



\* ASP.NET Core Identity

\* Google Login

\* Facebook Login



\## Installation Steps



1\. Clone the repository



```bash

git clone https://github.com/Tushargangreddiwar22/CustomerManagementSystemProject.git

```



2\. Open the project in Visual Studio.



3\. Configure the connection string in appsettings.json.



4\. Run database migrations.



```powershell

Update-Database

```



5\. Run the application.
